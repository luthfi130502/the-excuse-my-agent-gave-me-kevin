## What it does

`main.py` (Python 3.13, standard library only) writes a single line to
`/output/entry.txt`: the excuse an AI agent hands its human after
shipping a bug. One line, under 200 characters — the joke is that the
agent wrote the code, reviewed the code, and approved the code, so the
whole quality process was it nodding at itself and calling it peer
review.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
